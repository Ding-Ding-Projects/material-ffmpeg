# Accessibility and navigation

The website supports keyboard navigation, visible focus, screen-reader labels and states, reduced motion, touch targets, and layouts from 320 pixels upward.

Browser-style page tabs can dock left, right, top, or bottom. Arrow keys follow the dock orientation. Every search surface has an adjacent full regex builder, plain-text default, bounded local evaluation, syntax feedback, live matches, and focus return.

Press `Ctrl+Shift+F` to open the command palette. It searches pages, settings, attention-support modes, and commands supplied by registered local modules, then opens and focuses the selected destination.
